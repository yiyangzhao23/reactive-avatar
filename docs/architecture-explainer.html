Reactive Avatar · 架构与流程示意

桌面优先的 3D 虚拟角色：摄像头 + 屏幕共享感知，BYOK 调用 Gemini / OpenCode 网关，本地记忆与系统语音。
依据 docs/plan.md（P0–P4）绘制，非最终实现承诺。

公开 Beta 桌面 Web 香港 + 海外 BYOK · Key 仅本地 v1 不做 GPU TTS

1 · 系统架构

实线：当前原型已具备 / v1 计划 虚线：暂不实现（v2 或 Non-goal） BYOK：Key 只存在浏览器，不经服务器落库

2 · 对话与状态流程

01

输入

打字 / 麦克风 / 鼠标 / 摄像头 / 屏幕共享

02

本地感知

MediaPipe 人脸与表情，屏幕亮度与变化，生成观察文本

03

上下文

最近对话 + 剧情记忆 + 当前观察（截图仅在需要时携带）

04

路由

海外直连 Gemini；香港走 OpenCode 网关；失败回退本地规则

05

反应

情绪标签 + 一句台词（JSON 约束，失败原文兜底）

06

表达

表情 / 口型 / 手势 / TTS + 聊天记录与记忆写入

语音聊天

录音（WAV）→ 转写（Gemini 或网关音频）→ 作为用户消息 → 回复朗读。空白/超短音频直接丢弃。

屏幕分析（游戏）

截图 + 提示词 → 概况 / 线索 / 建议。开启剧情记忆时要求返回 {analysis, memory}，只存新事实。

鼠标互动

移动 → 1 秒内眼/头跟随（抬头受限、眼珠幅度受限）；拖动 → 转身 + 躯干惯性；互动期间暂停待机小动作。

状态：待机

呼吸 / 轻摆 / 眨眼；开页挥手一次；随机叉腰。

状态：说话

口型随语音节奏；情绪 6 秒后回落到 neutral。

状态：互动

拖动 / 视线期间抑制待机动作，结束后延迟恢复。

状态：降级

无 Key / 无摄像头 / 断网：提示缺什么，保留本地能力。

3 · 部署视图（目标形态）

静态前端

  • Cloudflare Pages / Vercel
  • HTTPS 必需（摄像头/屏幕）
  • CDN 缓存 + 版本化资源
  • PWA 离线壳

轻后端

  • /api/session + Turnstile
  • /api/llm · /api/stt
  • 限流 / 白名单 / 超时
  • 零 Key 存储

外部服务

  • Gemini API（海外）
  • OpenCode 网关（香港）
  • Cloudflare Turnstile
  • 模型 / 音频不落盘

v2 可选

  • GPU TTS（克隆音色）
  • 云端跨设备记忆
  • 移动端适配
  • 用户自传音色（需授权审核）

4 · 红线（Non-goals，v1）

不做移动端；iOS 无屏幕共享，不宣传不适配
不做中国大陆直连可用性
不做账号 / 支付 / 订阅（BYOK）
服务器不保存 Key / 截图 / 音频 / 聊天原文
不开放用户上传自定义音色
不做多人房间 / 直播 / 原生 App
不自建 GPU TTS，不对外提供克隆音色
不做服务端跨设备剧情记忆
