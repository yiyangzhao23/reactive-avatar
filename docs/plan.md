# Reactive Avatar 上线计划（v1 · 公开 Beta，桌面优先）

> 本文件是规划文档，不含实现细节。所有"待确认"项在开工前需拍板。

## 1. 已确认的产品决策

| 项 | 决策 |
| --- | --- |
| 发布形态 | 公开互联网（公网可访问），先以 Beta 形式发布 |
| 平台 | 桌面浏览器优先（Chrome / Safari / Edge，macOS / Windows） |
| 主要用户地区 | 香港 + 海外（Gemini API 在香港不可直接使用） |
| 账号体系 | 无；正式版为 **BYOK**（用户自帶 Key） |
| Key 处理 | Key 只保存在浏览器 localStorage；服务器不保存、不记录 |
| VRM 模型 | 「破茧」已确认可商用 |
| 语音方案（v1） | **不托管克隆音色**；统一使用浏览器/系统音色（站主音色仅本机开发/演示） |
| 用户自传音色 | v1 不开放；若未来开放，必须要求用户声明并上传授权证明 |
| 模型通道 | 海外：浏览器**直连 Gemini**；香港/不可直连：**OpenCode 閘道**（经后端代理，音频输入用支持 audio 的 gateway 模型） |
| 剧情记忆（v1） | **浏览器本地存储**（localStorage），跨设备不同步 |
| 反滥用 | **Cloudflare Turnstile** 保护后端代理；验证一次换短期 HttpOnly session cookie |

## 2. 范围（Scope）

**v1 必须交付**
- 3D 角色：加载、待机动画、挥手、叉腰、视线跟随鼠标、拖动转身
- 感知：摄像头（人脸/微笑）、屏幕共享（亮度/变化）、鼠标交互
- 对话：打字聊天、语音聊天（麦克风 → 转写 → 回复 → TTS）
- 能力：实时反应、`分析当前画面`、剧情记忆（开/关/清空）
- 语音：浏览器/系统音色（v1 不托管克隆音色）
- 双语：简体中文 / English（UI + 回复 + TTS 语言）
- PWA：可安装、离线壳、版本更新提示
- 合规基础：首次使用同意、隐私政策、合成角色标识、举报入口

**v1 明确不做（Non-goals / 红线）**
1. 不做移动端；iOS 的屏幕共享不可用，移动端不宣传、不适配
2. 不做中国大陆直连可用性（Gemini 区域限制，需用户自备可达网络/Key）
3. 不做账号、支付、订阅、额度体系（BYOK 模式）
4. 不在服务器保存或记录用户 Key、截图、音频原文、聊天原文
5. 不开放用户上传自定义音色（授权体系未就绪前一律关闭）
6. 不做多人房间、直播、实时连麦、原生 App
7. 不做 24/7 可用性承诺（Beta 尽力而为）
8. v1 不自建/不托管 GPU TTS，不对外提供克隆音色（成本原因，留待 v2 评估）
9. v1 不做服务端/跨设备剧情记忆（本地存储，清缓存即丢失）

## 3. 架构目标

```
浏览器（静态站）
  ├─ 3D / MediaPipe / PWA        ← CDN 或自托管静态资源
  ├─ Key: localStorage（仅本地）
  ├─ 海外：直连 Gemini（对话/看圖/語音）
  ├─ 香港/不可直连：/api/* 走代理
  ├─ Turnstile 首次验证 → /api/session（HttpOnly cookie）
  └─ 剧情记忆：localStorage
                │
后端（轻量）
  ├─ /api/session → Turnstile siteverify → 签发短期 HttpOnly cookie
  ├─ /api/llm   → OpenCode 閘道（需 session；白名单、透传 Bearer、限流、不记日志）
  ├─ /api/stt   → 网关音频转写（需 session；可选合并进 /api/llm）
  └─ 静态托管 / 健康检查

TTS：浏览器 Web Speech / 系统音色；本地 say 与 9880 服务仅开发模式
```

**关键约束**
- 公网站点必须 HTTPS（摄像头/屏幕共享硬性要求）
- `/api/llm` 不得成为开放代理：上游白名单 + 每 IP 限流 + 请求体大小/超时限制
- 用户 Key 仅透传，不得写入日志、指标或数据库
- 香港用户无法使用 Gemini TTS；v1 统一系统音色，不做公网克隆音色

## 4. 分步实施计划

### P0 · 基础与法务（约 1 周）
- [ ] 域名 + HTTPS + 部署账号
- [ ] 隐私政策 / 服务条款 / 音色授权条款（用户上传场景预留）
- [ ] 首次使用同意弹窗：摄像头、屏幕、第三方模型传输说明
- [ ] 合成角色标识常驻（"合成角色 · 不是人"）
- [ ] 安全响应头：CSP、`Permissions-Policy: camera=(self), display-capture=(self), microphone=(self)`
- [ ] Cloudflare Turnstile：创建 widget（域名白名单）、site key / secret 环境变量、localStorage 隐私说明
- **交付**：可访问的空壳站点 + 合规页面

### P1 · 后端与 Key 路径（约 1–2 周）
- [ ] `/api/session`：Turnstile siteverify → 签发 HttpOnly 签名 cookie；`/api/*` 中间件校验 cookie + 每 IP 限流
- [ ] `/api/llm` 代理：上游仅 `opencode.ai/inference`，透传 Authorization，禁止日志，限流（每 IP/分钟），超时与错误归一化
- [ ] 直连 Gemini 探测：可用则直连，不可用自动切代理（或按 provider 手动选择）
- [ ] 语音转写：改用网关音频模型（Gemini audio input），移除"必须 Gemini Key"的限制
- [ ] 语音：生产环境统一系统音色；本地 say/TTS 仅开发模式，不对外提供服务
- [ ] 展示当前语音状态（系统音色），Safari 首次交互解锁音频
- **交付**：BYOK 全链路在公网可跑，无 Key 落库/落日志

### P2 · 前端生产化（约 1–2 周）
- [ ] 模型投递：`model.vrm` 切分为 4 个 <25MiB 分片（`model-parts/`，文件名带内容哈希），前端拼接后解析；**不做有损压缩**（实测会破坏 VRM 贴图索引）
- [ ] 换模型流程：替换 `model.vrm` → `node split-model.js`（或 `--watch`）→ 本地验证 → 提交推送
- [ ] 依赖策略：CDN importmap 固定版本 + SRI，或打包自托管；评估可用性
- [ ] PWA：`sw.js` 预缓存改为带版本号；更新提示；避免旧缓存
- [ ] Safari 音频解锁与自动播放回退；摄像头/共享停止状态同步（已有）
- [ ] 加载进度、弱网/无摄像头/无 Key 的降级文案
- [ ] 错误监控（Sentry，前端）+ 使用指标（不含 PII/画面/音频）
- [ ] 剧情记忆改为浏览器本地存储（服务器 DB 留待 v2）
- **交付**：首屏、缓存、错误处理达标

### P3 · 兼容性与 QA（约 1 周）
- [ ] 桌面矩阵：Chrome/Safari/Edge × macOS/Windows
- [ ] 场景测试：无 Key、无摄像头、拒绝权限、断开共享、切标签页、断网
- [ ] 滥用测试：代理限流、超大请求、异常模型名、超时
- **交付**：测试报告 + 已知问题清单

### P4 · Beta 发布（约 1 周）
- [ ] 邀请制灰度 → 公开
- [ ] 监控告警：错误率、代理 429、可用性
- [ ] 回滚方案与发布记录
- [ ] 反馈渠道与问题跟踪
- **交付**：公开 Beta 上线

## 5. 已确认的補充決定

1. **剧情记忆**：v1 使用浏览器本地存储（跨设备不同步，清缓存即丢失）。
2. **模型通道**：海外直连 Gemini；香港/不可直连走 OpenCode 閘道（經後端代理）。
3. **反濫用**：Cloudflare Turnstile，驗證一次換短期 session cookie，`/api/*` 全部受保護。

## 6. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 首屏 75MB 下载（4 分片） | 分片加载 + 加载状态 + CDN 强缓存；后续再做 VRM 感知优化 |
| 香港无法用 Gemini TTS | v1 统一系统音色，不依赖 Gemini TTS |
| `/api/llm` 被滥用 | 白名单 + 限流 + 体积/超时限制 + 监控 |
| 系统音色机械感 | UI 明示；后续版本再评估云 TTS（按量付费） |
| 用户误共享敏感内容 | 共享前提示、可一键停止、隐私说明 |
| Turnstile 不可用 | 降级为仅本地功能可用，提示稍后重试；`/api/*` 保持关闭 |
| 用户上传侵权音色 | v1 关闭上传；未来需授权声明 + 审核 |
| Safari 音频/语音异常 | 首次交互解锁、失败回退、状态可见 |
| 旧 PWA 缓存 | 版本化缓存 + 更新提示 + 强制刷新路径 |
